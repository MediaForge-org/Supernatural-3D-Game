## Statuslegende

| Zeichen | Bedeutung |
|---|---|
| ✅ | Implementiert und getestet. **Trifft in diesem Ordner auf nichts zu.** |
| 📋 | **Bestätigte Planung:** Der Entwickler hat die Richtung ausdrücklich bestätigt. Nicht implementiert. Zum Teil noch nicht in den Kanon konsolidiert. |
| 🧭 | **Vorläufig oder Vorschlag:** Arbeitsstand, Entwurf oder Vorschlag (meist eines KI-Assistenten), nicht als Entscheidung bestätigt. |
| 🔭 | Langfristige Vision ohne Spezifikation. |
| ❓ | Offen: bewusst oder noch nicht entschieden. |
| 🕰️ | Überholt: frühere Planung, später ersetzt. |
| ⛔ | **Nicht freigegeben oder ausgeschlossen:** geäußerter Wunsch oder Entwurf, der nicht als Planung oder Spielmechanik gilt. |

Aussagen ohne Zeichen sind Einordnung oder Erklärung. Vorschläge eines Assistenten gelten nur dann als bestätigt, wenn der Entwickler ausdrücklich zugestimmt hat; dann ist das genannt.

## Konventionen

- Die Dokumente sind **ohne Zugriff auf den externen Master** lesbar. Quellenpfade stehen gesammelt in [Modul 12](12-Entscheidungsverlauf-und-Quellen.md).
- Sie enthalten **keinen Katalog expliziter Handlungen**. Die Taxonomie wird auf Struktur- und Metadatenebene beschrieben.
- Sie sind **kein Rechtsrat** und treffen **keine Entscheidungen**; Entscheidungen trifft der Entwickler.
- Pro Modul stehen, wo sinnvoll, **ableitbare Tests** als Vorschlag; es gibt keinen Code und keine Tests für diesen Bereich.
