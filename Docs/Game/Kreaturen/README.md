# Kreaturen-Dokumentation: Index

> [!IMPORTANT]
> **Nichts davon ist implementiert.** Dieser Ordner dokumentiert den **Planungsstand** von Kreaturen, übernatürlichen Wesen, Monster-KI und Bestiarium aus dem externen Planungs-Master und den Gesprächsverläufen. Er erfindet keine Entscheidungen und keine Arten. Es gibt **keine beschlossene Artenliste**; was die Quellen offenlassen, bleibt offen (Modul 21). Entwürfe sind als „Entwurf“ gekennzeichnet (💡) und **kein Kanon**. Der Zielumfang von 10.000 bis 15.000 Zeilen ist **nicht erreicht**; das tatsächliche Maß steht in [Modul 22](22-Abdeckungsprotokoll.md).

Teil der Spiel-Dokumentation: [Spielvision](../Spielvision.md) (Überblick §9 und §10), [Gameplay-Systeme](../Gameplay-Systeme.md) (§8, §9), [Spielwelt und Untergrund](../Spielwelt-und-Untergrund.md), [Entscheidungsstatus](../Entscheidungsstatus.md), [Ermittlungs-Dokumentation](../Ermittlung/README.md), [Welt-Dokumentation](../World/README.md).

## Statuslegende

| Zeichen | Bedeutung |
|---|---|
| ✅ | implementiert und getestet (in diesem Ordner nirgends) |
| 📋 | bestätigt: vom Entwickler festgelegt oder im Master als akzeptiert geführt, nicht implementiert |
| 🧭 | vorläufig: Arbeitsstand, Szenario, Kandidat |
| 💡 | Vorschlag oder Beispiel des Assistenten, nicht beschlossen |
| 🔭 | langfristige Vision ohne Spezifikation |
| ❓ | offen: gestellt, nicht beantwortet |
| 🕰️ | historisch ersetzt: bleibt als Geschichte stehen |
| ⚠️ | widersprüchlich: keine Ersetzung belegt |
