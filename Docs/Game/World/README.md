# Welt-Dokumentation: Index

> [!IMPORTANT]
> **Nichts davon ist implementiert, und keine Karte der größeren Welt ist freigegeben.** Dieser Ordner dokumentiert den **Planungsstand** der Spielwelt (Geografie, Städte, Untergrund, Fahrzeuge, Weltgenerierung) aus dem externen Planungs-Master. Er erfindet keine Entscheidungen. Der Master reicht für die Weltkarte nur bis **19.10.2026**.

Teil der Spiel-Dokumentation: [Spielwelt und Untergrund](../Spielwelt-und-Untergrund.md) (Überblick), [Spielvision](../Spielvision.md), [Gameplay-Systeme](../Gameplay-Systeme.md), [Entscheidungsstatus](../Entscheidungsstatus.md), [Adult-System](../Adult-System.md).

## Statuslegende

| Zeichen | Bedeutung |
|---|---|
| ✅ | implementiert und getestet (in diesem Ordner nirgends) |
| 📋 | bestätigt: vom Entwickler festgelegt oder in der Quelle als bestätigt geführt, nicht implementiert |
| 🧭 | vorläufig: Arbeitsstand, Szenario, Kandidat |
| 💡 | Vorschlag des Assistenten oder Engineering-Notiz, nicht beschlossen |
| 🔭 | langfristige Vision ohne Spezifikation |
| ❓ | offen: gestellt, nicht beantwortet |
| 🕰️ | historisch ersetzt: bleibt als Geschichte stehen |
| ⚠️ | widersprüchlich: keine Ersetzung belegt |
