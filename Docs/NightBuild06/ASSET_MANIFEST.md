## 3. Strategy (selective; implemented: step 1 only)

1. **Version `Content/SpnTest/**` in LFS (implemented, not committed).**
   - Why: own, script-generated, 4 MB; every headless and QA suite except World needs it.
   - Done:
     - `.gitignore` re-includes only `Unreal/SupernaturalProt/Content/SpnTest/**/*.uasset|*.umap`;
     - `.gitattributes` already routes them to LFS (`git check-attr filter` = `lfs`, checked);
     - `git status` now lists exactly these 39 files as untracked;
     - every other `Content/` folder is still ignored (checked with `git check-ignore` on Fab, SpnWorld, SpnCharacterPrep).
   - Commit: optional commit E in the README commit plan.
2. **Do not version third-party content**: `Fab/`, `Megaplant_Library/`, `SpnWorld/FabDerived/`.
   - Provisioning: the developer's Fab library. The paths are in Fab-Asset-Sources.md.
   - The world generator falls back to procedural placeholders when they are missing.
3. **MetaHuman-generated content** (`SpnCharacterPrep/`, `Characters/ProtagonistV1/`): keep out of git (licence, 380 MB).
   - `SpnCharacterPrep` can be regenerated with the setup scripts.
   - `ProtagonistV1` cannot. It needs a real backup on a second medium (section 4) or, after a licence decision, a private LFS
     store.
4. **SpnWorld (own, 554 MB, generated)**: not in git for now.
   - A rebuild takes the generator phases B–H and the Fab sources for the full look.
   - Option for later: a private LFS store or a release artefact (a ZIP of the content folder) per milestone. Developer decision
     (size, LFS quota, licence of the placed Fab instances).
5. **Fresh-checkout check (after commit E):** a clone plus `git lfs pull` should then have every test map except `Lvl_SpnWorld`.
   - Verify with `asset_dependency_report.py` in the clone.
   - Not run tonight: it needs a clone plus LFS objects, and nothing is committed yet.
