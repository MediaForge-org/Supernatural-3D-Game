# Nachtläufe 01 bis 04

Keine Meilensteine im engeren Sinn, sondern autonome Arbeitsläufe mit eigenem Umfang. Jeder Lauf hat eine eigene README mit Status und Grenzen.

| Lauf | Thema | Kern-Dokument | Status laut Quelle |
|---|---|---|---|
| NightBuild01 | Architektur, Bewegungsuntersuchung, Testumgebung | `Docs/NightBuild01/README.md`, `KNOWN_ISSUES.md` | Engineering-Vorschläge zur Prüfung, nicht Kanon |
| NightBuild02 | Straßen, Routing, Navigation, NPC-Gedächtnis, Speichern | `Docs/NightBuild02/README.md`, `MapNavigation/` | Core umgesetzt und getestet (Fedora). Vorschlag `Docs/Proposals/0012` |
| NightBuild03 | Demo-Navigation in Unreal, synthetische Region | `Docs/NightBuild03/KNOWN_ISSUES.md` | Demo mit Platzhaltern, Autopilot |
| NightBuild04 | Türen, Schlüssel, Aufbrechen (Platzhalterregeln) | `Docs/NightBuild04/KNOWN_ISSUES.md` | Platzhalter, keine Kanonregeln |

Die Läufe sind Quellen für Einträge in `TASKS.md`. Sie entscheiden nichts über den Kanon.
